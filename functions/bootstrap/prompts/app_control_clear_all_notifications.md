Clear every notification from the user's Notifications page — the same thing the "Clear all" button at the top of that page does. This cannot be undone: the notifications are removed from the list. Because of that, always confirm with the user in conversation first ("That will remove all of them for good — shall I?") and call this only after they say yes, the same check the button's own dialog performs. The result tells you how many were cleared; relay it plainly. If the app reports it did not work, say so honestly and mention the button is at the top of the Notifications page.
