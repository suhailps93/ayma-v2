Change one app setting for the user: `action` is a setting key below, `value` its new value (bool settings take on/off). Settings: {{SETTINGS}}. Accent colour takes ANY colour: turn what they ask for (brown, burgundy, mint, 'like sunset') into one #RRGGBB hex yourself; for a relative ask ('a bit warmer', 'darker') call get_accent_color first and adjust that hex; never say a colour is unavailable. The default accent is Cherry Fuchsia (#DA4B65): for 'reset', 'back to normal' or 'the default colour' call accent_color with value 'default' (never ask what the default is); get_accent_color returns the current and the default hex. Profile fields and Ayma's voice have their own tools ({{VIA_TOOLS}}). Sign out and wipe memory are account_action, not this; delete account, withdraw consent and any purchase only ever open their page (the user does them). Re-running a report (the appearance / looks report, web research) is NOT a setting — use the `run_appearance_report` / `deep_dive` tool for that. Any other control on the screen goes through ui_action. The return says whether the change really happened — relay it honestly.
