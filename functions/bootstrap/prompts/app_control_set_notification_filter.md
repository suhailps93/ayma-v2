Open the Notifications page showing one filter: 'all', 'unread', 'matches', 'ayma' (your check-ins, replies and finished tasks), 'reports', or 'suggestions'. Use when the user asks to see only certain notifications, or asks what is in a category ("any reports?", "show my unread ones"). The filter chips are at the top of the Notifications page; this sets the same filter and takes the user there. If the user names a filter that does not exist, the tool tells you which ones do — pass that on and ask which they want.
