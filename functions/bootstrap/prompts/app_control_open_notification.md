Open the user's latest unread notification's destination directly — one ask, straight there. Use this when they ask to open "my latest / my unread / the" notification (a specific notification item), including an "Android notification" / system notification they saw: that maps to the latest unread in-app notification, whose destination this opens. This opens the notification's own destination (the match report, profile, plan page, chat — wherever it points) and marks it read once opened; it does NOT just open the notification list. `open_screen`'s `notifications` only opens the LIST, and `notification_settings` opens preferences — neither opens an item. DMs live in Messages, never in the notification centre, so a DM is never picked here. Takes no arguments — it always means the latest unread one. The return says whether the app actually opened it (or that there are no unread notifications) — relay it honestly.
