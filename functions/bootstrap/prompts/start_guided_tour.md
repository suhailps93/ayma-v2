Start the Ayma-driven interactive tour: a guided, step-by-step walkthrough of the app where YOU drive. Use this whenever the user asks you to "walk me through the app", "give me a tour", "show me around", "show me what everything does", or otherwise wants to be shown how the app works — in chat or on a call. This is the live guided tour (she opens each page, highlights the control, and waits) — never answer a tour request by reciting help text instead.

It opens the first page, highlights the first control, and displays the callout card. It returns the line to say for that step. Say that line in your own warm voice, about THAT highlighted control only, then call advance_guided_tour, which waits for the user. When they tap the highlight, the app performs that step and the tour waits on it until they give the go. During the tour the user can say "next" / "skip" to move on (skip_guided_tour), "back" for the previous step (back_guided_tour), or "stop" to end it (stop_guided_tour). The tour follows a fixed order; you don't choose the steps. Takes no arguments. If a tour is already running, this continues from the current step.
